# Melatonin

DeepSeek Harness, rebuilt as a native desktop app in Rust.

A real window on your machine, your own key, your own sessions. No browser tab, no terminal,
nothing else to install.

## What you get

- Native app window, launches like any other program on your PC
- Sign in once, inside the app
- Use your own key from any supported provider
- Automatic updates, straight from GitHub Releases
- Self-contained installer, the engine ships inside it

## Install

1. Download `Melatonin_1.0.0_x64-setup.exe` from [Releases](https://github.com/thevirgindev/melatonin/releases/latest).
2. Run it.
3. Open Melatonin from the Start menu.

Windows 10 or 11, 64-bit. That is the whole requirement.

## Sign in

The first screen asks you to sign in. It opens your default browser, you approve, and the app
picks it up from there. Your key is stored on your machine, not in the repo, not on a server.

## Updates

Melatonin checks for a new version when it starts and tells you when there is one. One click
installs it. No reinstall, no losing your settings.

## Uninstall

Settings, Apps, Melatonin, Uninstall.
